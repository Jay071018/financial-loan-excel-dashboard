# Financial Loan Analysis Dashboard

## Project Overview
This project analyzes 38,576 loan records using Microsoft Excel to identify patterns related to credit risk and loan performance.

The project includes data cleaning, calculated fields, PivotTable analysis, KPI calculations, and an interactive-style dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel formulas
- Data cleaning and transformation
- Data visualization

## Key Metrics
- Total Loans: 38,576
- Total Loan Amount: $435,757,075
- Total Payment Received: $473,070,933
- Average Interest Rate: 12.05%
- Average DTI: 13.33%
- Bad Loan Rate: 16.67%

## Key Findings
- Grade A loans had the lowest bad loan rate at approximately 6.06%.
- Bad loan rates increased significantly for lower credit grades.
- Grade F and G loans had bad loan rates of approximately 37%.
- Borrowers earning under $40,000 had the highest bad loan rate at approximately 18.74%.
- Borrowers earning over $100,000 had the lowest bad loan rate at approximately 13.91%.

## Analysis Performed
- Loan performance classification
- Credit grade risk analysis
- Income group risk analysis
- Debt-to-income analysis
- KPI dashboard creation
- PivotTable-based credit risk analysis

## Dataset
Financial Loan Dataset from Kaggle.

`financial_Loan_Analysis.xlsx` contains the complete analysis, PivotTables, and dashboard.
